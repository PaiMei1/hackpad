# Hackpad Macropad

A custom macropad built for Hack Club's Hackpad guide, submitted through Stardance.

## What it is

A [3]-key macropad built around a Seeed XIAO RP2040, custom PCB, 3D printed case, running QMK.

## Structure

- `cad/` — case assembly (.step) + Fusion source files
- `pcb/` — KiCad project files
- `firmware/` — QMK firmware
- `assets/` — screenshots
- `BOM.csv` — parts list
